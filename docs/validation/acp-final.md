## Contract review

- The native session host binds the workspace-tool bridge, decisions, and events to a conversation generation. It records prompt intent before calling the adapter and never automatically resends an uncertain dispatch. The adapter now prevents prompt/settings overlap and ignores late turn output; a closed adapter rejects further prompts.
- ACP `session/load` requires an advertised capability and never falls back to `session/new`. Replayed load output has no new turn, and host ingress drops replayed turn activities that lack their original Loop turn identity.
- Permission options are bounded and one-shot. Cancel/crash settles pending decisions once; cancellation refuses later permission requests. Process errors now have a handler, and process exit rejects an in-flight mode confirmation.
- ACP JSONL frames are bounded at 8 MiB before SDK parsing. The shared activity parser applies smaller display limits. Unhosted terminals are reported as unavailable; advertised catalogs and confirmed settings are used rather than guessed.
